安装方式

所有插件都是 c-shared 动态库（CPA 的 Go 插件需宿主与插件共享包逐字节同源，升级易失效）。

1. 把动态库放进 CPA 插件目录

文件名（去扩展名）就是插件 ID：qoderwork · qoder · workbuddy-cpa。

2. 在 config.yaml 里启用

plugins:
  enabled: true
  dir: "~/.cli-proxy-api/plugins"
  configs:
    qoderwork:   { enabled: true }
    qoder:        { enabled: true, priority: 200 }
    workbuddy-cpa: { enabled: true, priority: 100 }

也可以在 CPA 管理面板 → 插件页直接点「启用」，会自动写入配置并热加载，无需重启。
