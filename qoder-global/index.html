Qoder 国际版（qoder.com）插件

把 Qoder 国际版封装成 CLIProxyAPI 的 Provider 插件。执行器把 OpenAI chat-completions 请求 原样转发到上游，完整保留 tools / tool_calls / tool_call_id， 可直接用于 ZCode / Claude Code 的工具循环；并附带 campaign 签到、积分面板与 token 自动保活。

⌨ 源码与 Release 📁 插件目录 📦 安装
Go · c-shared 版本 v0.1.0 OpenAI 兼容透传 单模型 claude-opus-5-5

模型

v1 只暴露这一个模型；其他模型请求会返回 model_not_supported，不会静默回退到 Auto。

客户端调用名上游 key说明
claude-opus-5-5ultimateQoder 国际版「极致」模型；上游真实来源以官方为准

功能

OpenAI 兼容透传

请求原样转发到 https://api2-v2.qoder.sh/model/v1/chat/completions，保留 tools、tool_calls、tool_call_id。

双登录方式

OAuth 设备授权（CPA 管理面板 → Auth → Qoder 登录卡片），或 PAT 导入（面板顶部「导入 Qoder Global 凭证」）。

campaign 签到

面板支持单账号 / 全部签到，自动签到 10:00 / 21:00，签到后返回最新积分快照。

积分面板

账号卡片：昵称 / 积分 / 计划 / 签到状态 / 操作，外加最近调用记录。

token 自动保活

定时刷新访问 token，避免会话过期导致整条 provider 不可用。

路由稳定

若 CPA 中已有其他 provider 暴露同名 claude-opus-5-5，把本插件的 priority 调高即可稳定路由到 qoder。

安装

cd qoder
CGO_ENABLED=1 go build -buildmode=c-shared -ldflags "-X main.version=0.1.0" -o qoder.dylib .
cp qoder.dylib ~/.cli-proxy-api/plugins/
plugins:
  configs:
    qoder:
      enabled: true
      priority: 200   # 其他 provider 也暴露 claude-opus-5-5 时，用它钉住 qoder
      # checkin_auto: true
      # token_keepalive: true
      # checkin_fingerprint: '{"machine_id":"...","machine_token":"...","machine_type":"..."}'

每日签到100 Credits

面板支持单账号 / 全部签到，自动签到 10:00 / 21:00。 国际版的每日 100 Credits 活动只对真实设备指纹下发：UID 派生的机器头能拉到部分活动， 但 CLAIM_BENEFIT 不会出现。macOS 官方客户端所在机器可运行： 

./scripts/detect_fingerprint.sh

把输出整行填入配置（注意输出含设备 token，不要外传）：

checkin_fingerprint: '{"machine_id":"...","machine_token":"...","machine_type":"...","machine_code":"..."}'
没有本机客户端时，可先在官方 Qoder 客户端领取一次（之后懒下发），或从官方客户端抓包取得 machine_token / machine_type。配置后重启 CPA，面板签到即可看到当日活动； 当天已领取会显示「今日已签到」。

实测记录2026-10-21

200非流式 claude-opus-5-5：上游 model=ultimate，usage 正常。
200流式简单对话：标准 OpenAI chunk。
200流式工具调用：tool_calls 增量透传；非流式工具往返（tool_call → tool result → 最终回答）通过。
200Anthropic /v1/messages：ANTHROPIC_OK。
200签到 campaign：上游返回当日 CLAIMED；派生机器头可正常拉取活动列表。

已知限制

Ultimate 权益不稳定：同一账号的部分请求会返回上游 provider_error （如 model "claude-opus-4-6" is not available for this account、Bedrock InvokeModelWithResponseStream 显式拒绝、Required egress proxy not available）。 这是 Qoder 上游路由 / 套餐权益问题，插件会把原始错误透出；失败请求可能触发 CPA 60 秒账号冷却。 建议使用有 Ultimate / 极致权益的付费账号。
图片 data URL：上游对 data:image/... 返回 Could not process image。 v1 未实现 COSY 图片上传，需要图片输入时走二期上传链路。
签到：国际版活动按设备指纹下发；新号先在官方客户端领取一次（之后懒下发）， 或在配置中提供真实 checkin_fingerprint。
